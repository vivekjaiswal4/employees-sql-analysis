# Employee SQL Analysis

## About the Project
This is my first SQL project using PostgreSQL.

I created an employee database containing 15 employee records and practised SQL queries to retrieve and analyse data.

## Database
- PostgreSQL

## Topics Covered
- SELECT
- WHERE
- ORDER BY
- LIMIT
- DISTINCT
- BETWEEN
- AND / OR
- LIKE
- Aggregate Functions

## Dataset
15 employee records with:
- Employee ID
- First Name
- Last Name
- Department
- Salary
- City
- Age

## Objective
To improve my SQL skills and develop a foundation for Data Analytics.
